# Свои картинки для РП-команд

Бот сначала ищет картинку здесь, и только если её нет — тянет гифку
из nekos.best. Так что свои файлы важнее API.

Положи файл с нужным именем (расширение любое: .gif, .png, .webp, .jpg):

| Команда       | Имя файла        |
|---------------|------------------|
| `/обнять`     | `hug`            |
| `/поцеловать` | `kiss`           |
| `/погладить`  | `pat`            |
| `/приобнять`  | `cuddle`         |
| `/угостить`   | `feed`           |
| `/помахать`   | `wave`           |
| `/чмок`       | `blowkiss`       |
| `/пнуть`      | `kick`           |
| `/шлёпнуть`   | `slap`           |
| `/стукнуть`   | `bonk`           |
| `/укусить`    | `bite`           |
| `/ткнуть`     | `poke`           |
| `/пощекотать` | `tickle`         |
| `/пять`       | `highfive`       |
| `/держаться`  | `handhold`       |

Пример: `hug.gif` или `hug.png`.

## Картинки по полу пары (необязательно)

Если хочется, чтобы на гифке были те, кто обнимается, а не случайные
аниме-девушки — добавь к имени суффикс пары, и бот выберет нужный файл:

| Суффикс | Когда берётся        |
|---------|----------------------|
| `_mm`   | оба с ролью ♂        |
| `_ff`   | оба с ролью ♀        |
| `_mf`   | один ♂, другой ♀     |

Пример: `hug_mm.gif`, `kiss_ff.png`, `pat_mf.webp`.

Порядок поиска: сначала файл под пару (`hug_mm.gif`), потом общий
(`hug.gif`), потом гифка из API. Так что можно закинуть только те пары,
которые нужны, а остальные останутся на API.

Необязательно всё: работает и без единого локального файла.

После добавления файла нужен рестарт бота — картинки не кешируются.
