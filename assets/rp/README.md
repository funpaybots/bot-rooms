# Свои картинки для РП-команд

Бот сначала ищет картинку здесь, и только если её нет — тянет гифку
из nekos.best. Так что свои файлы важнее API.

Положи файл с нужным именем (расширение любое: .gif, .png, .webp, .jpg):

| Команда       | Имя файла        |
|---------------|------------------|
| `/обнять`     | `hug`            |
| `/поцеловать` | `kiss`           |
| `/погладить`  | `pat`            |
| `/приобнять`  | `cuddle`         |
| `/угостить`   | `feed`           |
| `/помахать`   | `wave`           |
| `/чмок`       | `blowkiss`       |
| `/пнуть`      | `kick`           |
| `/шлёпнуть`   | `slap`           |
| `/стукнуть`   | `bonk`           |
| `/укусить`    | `bite`           |
| `/ткнуть`     | `poke`           |
| `/пощекотать` | `tickle`         |
| `/пять`       | `highfive`       |
| `/держаться`  | `handhold`       |

Пример: `hug.gif` или `hug.png`.

После добавления файла нужен рестарт бота — картинки не кешируются.
